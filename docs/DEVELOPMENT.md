# Development

**English** · [한국어](DEVELOPMENT.ko.md)

## Building

You need Rust (GNU toolchain) and MinGW-w64.

```powershell
winget install Rustlang.Rustup
rustup default stable-x86_64-pc-windows-gnu
winget install BrechtSanders.WinLibs.POSIX.MSVCRT
```

The build produces `dist\TB-Notepad.exe`. If the app is running and the exe is locked, the old file is moved aside and the new one put in place.

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Tests: `cargo test`

- The apostrophe in the folder name (`TB's`) breaks the MinGW linker, so `.cargo/config.toml` moves the build output to `%LOCALAPPDATA%\tb-notepad\target`.
- Regenerate the logo with `python scripts/make-logo.py` (`assets/logo.png`, `assets/logo.ico`). `build.rs` embeds `assets/app.rc` (icon and version info) with windres.
- The exe only depends on DLLs that ship with Windows, so copying the single exe to another PC is enough.

## Settings and data

- Settings and session: `%APPDATA%\tb-notepad\data\app.ron`
- A `portable.txt` next to the exe keeps everything in a `data` folder beside it (for USB drives).
- The `TB_NOTEPAD_DATA` environment variable picks the data folder and also puts the default notes folder inside it (handy for tests).

## UI languages (한국어 · English · 中文 · 日本語)

UI strings are written in Korean in the code and wrapped as `t!("저장")` / `tf!("{} 저장됨", name)` (`src/i18n.rs`).
Translations live in `scripts/i18n_strings.py`; after editing it, run `python scripts/gen-i18n.py` to regenerate `src/i18n_table.rs`.
The script reports strings without a translation and translations whose `{}` count doesn't match.
The language is chosen in Settings › Editor; "Automatic" follows the Windows display language.
The guide note written on first launch is `samples/welcome/<lang>.md`.

## How Ctrl+V image paste works

egui silently swallows Ctrl+V when the clipboard has no text. On Windows the window is subclassed so the key is seen before winit,
and an image paste runs only when the clipboard has an image or files but no text (`src/paste_hook.rs`).

## How the document view works

The text itself is never changed (so TextEdit can keep editing it); only its look is (`src/live.rs`).
Symbols such as `**` and `#` are hidden as nearly zero-width transparent glyphs, while bullets, checkboxes, quote bars, tables, images
and audio/video cards are painted separately at the laid-out glyph positions (`src/app/decorations.rs`).
Rows that need height, like images and tables, reserve it through the line height of their hidden glyphs.
