# 欢迎使用 TB's Notepad

一款边写边显示格式的轻巧易用记事本。这一篇笔记就能看完基本用法和所有可用的 Markdown 语法。

![TB's Notepad](images/welcome.png "align=center")

-# 这也是一篇普通笔记，可以随意修改或删除。

## 第一步

- [x] 获取 TB's Notepad
- [ ] 用左侧边栏的 **新建笔记** 写第一篇笔记
- [ ] 用右上角的 ☀ / 🌙 切换浅色 · 深色
- [ ] 点击上面的图片，改改它的大小和位置
- [ ] 在空行输入 `/` 打开命令列表
- [ ] 按 Ctrl+E 查看这篇笔记的源码（Markdown 符号）

## 界面一览

- **左侧边栏**：搜索、新建笔记、添加文件夹，以及 文件夹 › 子文件夹 › 笔记 列表
- **顶部栏**：当前笔记的位置（文件夹 / 名称）、查找、源码视图、浅色 · 深色、设置、⋯ 菜单
- **格式工具栏**：粗体 · 斜体 · 删除线 · 代码 · 标题 1–3 · 列表 · 待办 · 引用 · 代码块 · 表格 · 分隔线 · 链接 · 图片 · 音频 · 视频 · 文件链接
- **底部状态栏**：行 · 列、字数、保存状态、编码、换行符、文字大小

## 新建与整理笔记

- **新建笔记** (Ctrl+N)：直接建在当前查看的文件夹里。第一行写的内容就是文件名。
- **自动保存**：停止输入后立即保存，不需要手动保存。
- **添加文件夹**：把存放笔记的文件夹加入侧边栏。也可以把文件夹拖到窗口上。
- 文件夹旁的 **+** 会在该文件夹中新建笔记。文件夹里可以再建任意层文件夹。
- **右键** 笔记或文件夹可以新建文件夹、重命名 (F2)、在资源管理器中显示、移到回收站。
- **搜索** (Ctrl+P)：在所有文件夹中同时查找文件名和内容。
- 在侧边栏把笔记或文件夹 **拖到其他文件夹上** 即可移动。笔记中的图片、链接，以及指向它的其他笔记中的链接也会一起更新。
- 其他位置的文件可以拖到窗口上，或用 ⋯ › 打开文件 (Ctrl+O) 打开，会显示在侧边栏的“已打开的文档”中。

## `/` 命令

不用记快捷键。在行首或空格后输入 `/`，就会弹出可以做的事情列表。

- 继续输入可筛选列表：`/标题`、`/链接`、`/h2`、`/todo`。
- 用 ↑ ↓ 选择，按 **Enter**（或 Tab、鼠标点击）执行。输入的 `/关键词` 会被删除。
- 输入 **空格** 或按 Esc 会关闭列表，`/` 作为普通文字保留。
- 包含的命令：标题 1–3 · 项目符号列表 · 编号列表 · 待办 · 引用 · 小字 · 代码块 · 表格 · 分隔线 · 网页链接 · 笔记链接 · 复制此行链接 · 文件链接 · 文件夹链接 · 图片 · 音频 · 视频 · 剪贴板图片 · 日期和时间 · 今天的日期 · 表情
- 像 `10/15`、`a/b` 这样紧跟在文字后的 `/` 不会打开列表。

## 列表与折叠块

- 在项目符号、编号、待办或引用行按 **Enter**，下一行会自动接上相同的符号。在空项目上再按一次即结束列表。
- 用 **Tab** / **Shift+Tab** 缩进或取消缩进列表项。
- 在行首输入 `>>` 和空格即成为 **折叠块**（可展开 / 收起的块）。也可以用 `/折叠块` 或格式菜单插入。
- 点击标题前的 ▶，或在标题行按 **Ctrl+Enter** 即可展开 / 收起。里面可以写列表、图片等任何内容。
- 折叠块以 `<details>` 格式保存，在 GitHub 和 VS Code 中同样可以折叠。

## Markdown 语法

输入符号后格式立即显示，符号只在光标所在行淡淡地显示。也可以用工具栏或快捷键插入。

### 文字样式

- `**粗体**` → **粗体** (Ctrl+B)
- `*斜体*` → *斜体* (Ctrl+I)
- `~~删除线~~` → ~~删除线~~
- `` `代码` `` → `代码`
- `[链接文字](https://example.com)` → [链接文字](https://example.com)（Ctrl+K，**Ctrl+点击** 打开）
- 直接写网址也会变成链接：https://example.com
- `[会议记录](会议/10月.md)` → 指向其他笔记的链接。**Ctrl+点击** 即可打开
- `[决定事项](会议/10月.md#决定事项)` · `[第 12 行](会议/10月.md#L12)` → 直接跳到那篇笔记的标题或某一行
- `[回到顶部](#L1)` · `[Markdown 语法](#markdown-语法)` → 在当前笔记内跳转：[前往 Markdown 语法](#markdown-语法)
- `[会议文件夹](会议)` → 笔记文件夹中的文件夹会在侧边栏中展开
- `[报告](C:/资料/报告.pdf)` → 非笔记的文件和其他位置的文件夹会在资源管理器中打开（含空格的路径用 `<...>` 括起来）

### 行样式（写在行首）

- `# 标题` · `## 标题` · `### 标题` → 从大到小的标题 (Ctrl+Alt+1–3)
- `- 项目` → 项目符号列表（前面加两个空格成为子列表）
- `1. 项目` → 编号列表
- `- [ ] 待办` · `- [x] 已完成` → 复选框（点击即可勾选）
- `> 引用` → 左侧带竖条的引用
- `-# 小字` → 灰色小号的补充文字
- `>> 标题` → 可展开 / 收起的折叠块（输入空格时立即转换）
- `---` → 水平分隔线

### 多行样式

- 代码块：在上下各写一行三个反引号 (```) 把内容括起来。第一行后面可以写语言名。
- 表格：用竖线分隔单元格，如 `| 单元格 | 单元格 |`。第二行是 `| --- | --- |`，`:---:` 居中，`---:` 右对齐。光标不在表格时显示为表格，点击后变回源码方便编辑。可以用 `/表格` 快速插入。

### 图片 · 音频 · 视频

- `![说明](images/图片.png)` → 只有图片的一行会直接显示图片。
- `![说明](images/图片.png "width=50% align=center")` → 大小（正文宽度的 %）和水平位置（left · center · right）
- `![说明](音乐/歌曲.mp3)` → 音频文件显示为带进度条的音频卡片 (mp3 · wav · flac · ogg · m4a · aac)
- `![说明](视频/片段.mp4)` → 视频文件显示为带首帧画面的视频卡片 (mp4 · webm · mkv · mov · avi · wmv)

## 插入图片

- **复制图片后按 Ctrl+V**，图片会以 PNG 保存到笔记旁的 `images` 文件夹并立即显示。
- 也可以把图片文件 **拖到窗口上**，或用工具栏的图片按钮选择文件。
- **点击图片** 会出现工具栏：25 · 50 · 75 · 100% · 原始大小，左 · 居中 · 右，删除
- 拖动所选图片的 **角** 可以像 Word 一样调整大小。Delete 删除，Esc 取消选择。
- 光标只会停在图片前后。在图片后按 Enter 会在下面新起一行。
- 其他位置的图片在插入或保存时会复制到笔记文件夹中一起保存（可在设置中关闭）。

## 音频与视频

- 用工具栏的图片按钮（或 ⋯ › 编辑 › 插入图片 · 音频 · 视频）选择音频或视频文件，或 **拖到窗口上**。
- **音频** 可以直接在笔记中播放：▶ 播放 · 暂停，点击或拖动进度条跳到想听的位置。
- 用音频卡片右侧的 **扬声器和小滑块** 调整音量。点击扬声器静音，再点一次恢复。音量会被记住。
- **视频** 显示为带首帧画面的卡片，点击中间的 ▶ 或双击卡片会用默认播放器打开。
- 卡片也可以像图片一样点击后调整大小 · 位置或删除。
- 音频和视频文件较大，不会复制到笔记文件夹，而是指向原文件。移动文件后卡片会显示“找不到文件”。

## 自定义表情

像 Discord 一样，可以把自己的图片当作文字大小的表情使用。

- **添加**：在正文图片上右键 › **添加为表情…**，或 `/表情` › **用图片添加新表情…**，选择图片并起个名字。
- **插入**：在空格后输入 `:` 和名字的开头（`:猫`），就会出现匹配的表情。按 Enter 插入，或完整输入 `:猫咪:` 即可直接变成表情。
- 表情像一个字一样：紧跟在后面按一次 Backspace 就会删除。
- 图片保存在笔记文件夹的 `.emoji` 文件夹中，会随笔记一起同步。正文中以普通图片语法 `![:猫咪:](.emoji/猫咪.png "emoji")` 保存，其他 Markdown 应用会显示为普通图片。

## 笔记之间的链接

- **插入笔记链接** (Ctrl+Shift+K，或 ⋯ › 编辑)：按笔记或文件夹名查找并选择即可插入链接。
- **复制此行链接** (Ctrl+Shift+L)：复制指向光标所在行的链接。若是标题行，则链接到该标题。在其他笔记中按 Ctrl+V 粘贴时，路径会自动改为相对于那篇笔记。
- 也可以在侧边栏 **右键笔记或文件夹 › 复制超链接**。
- 在正文中选中文字后 **右键 › 复制超链接**，会以所选文字为链接文字，复制指向该行的链接。正文右键菜单还有剪切 · 复制 · 粘贴 · 创建链接。
- **Ctrl+点击** 链接：笔记会在应用中打开（跳到那一行或标题），文件夹会在侧边栏中展开。

## 文件与文件夹链接

- 用工具栏的文件夹按钮（或 ⋯ › 编辑 › 插入文件链接 · 插入文件夹链接）选择这台电脑上的文件或文件夹即可插入链接。
- 把无法作为笔记打开的文件（pdf、Excel、压缩包等）拖到窗口上也会插入链接。按住 **Shift** 拖放文件夹会插入文件夹链接。
- 也可以在资源管理器中 **复制文件后按 Ctrl+V**：图片 · 音频 · 视频直接显示，其他文件插入为链接。
- **Ctrl+点击** 链接：文件夹在资源管理器中打开，文件会在资源管理器中被选中显示。笔记文件夹中的笔记和文件夹会在应用中打开。

## 视图与外观

- **源码视图** (Ctrl+E)：显示 Markdown 符号进行编辑，再按一次返回。
- **主题**：右上角 ☀ / 🌙 切换浅色 · 深色，在 设置 › 主题与颜色 中有 8 种主题和自定义颜色
- **字体**：在 设置 › 字体 中设置正文 · 源码视图 · 界面字体和缩放
- **文字大小**：Ctrl+鼠标滚轮、Ctrl+= / Ctrl+-，Ctrl+0 恢复默认
- 打开 / 关闭 **侧边栏**：Ctrl+\
- 设置 › 编辑器 中还有：语言、行号、正文宽度限制、格式工具栏、状态栏、窗口置顶
- 全屏：F11

## 查找与文件

- 查找 Ctrl+F，替换 Ctrl+H，下一个 / 上一个 F3 · Shift+F3
- 插入日期和时间：F5
- .txt 文件按纯文本打开，并按原文件、原编码（UTF-8、ANSI 等）和原换行符保存。
- 点击底部状态栏可以更改编码和换行符 (CRLF · LF)。
- 用 ⋯ › 导出为 HTML 可以保存为网页。音频和视频会使用浏览器的播放器。
- **历史版本**（⋯ › 编辑 › 历史版本，或在侧边栏右键）：可以查看并恢复编辑时每 5 分钟以及大量删除时保留的内容。
- 笔记在应用外被修改时会自动重新载入。如果两边都改了，会询问保留哪一边。

## 快捷键一览

- Ctrl+N 新建笔记 · Ctrl+O 打开文件 · Ctrl+S 保存 · Ctrl+W 关闭文档
- Ctrl+P 搜索笔记 · Ctrl+\ 侧边栏 · F2 重命名
- Ctrl+B 粗体 · Ctrl+I 斜体 · Ctrl+K 链接 · Ctrl+Alt+1–3 标题
- Ctrl+Shift+K 插入笔记链接 · Ctrl+Shift+L 复制此行链接 · Ctrl+点击 打开链接

- Ctrl+V 粘贴（也可粘贴图片）· Ctrl+Z / Ctrl+Y 撤销 / 重做
- Ctrl+E 源码视图 · Ctrl+, 设置 · F11 全屏

## 与 AI 一起使用

Claude 等 AI 应用可以读写这台电脑上的笔记（无需云端，无需登录）。在 AI 应用的设置中注册 `TB-Notepad.exe --mcp`，即可查看列表、读取、搜索、新建和修改笔记。

-# 设置和打开的文档记录保存在 %APPDATA%\tb-notepad。在程序旁放一个 portable.txt，就会改为保存在程序旁的 data 文件夹中。
