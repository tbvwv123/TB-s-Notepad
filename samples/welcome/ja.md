# TB's Notepad へようこそ

書いたそばから書式が反映される、軽くてかんたんなメモ帳です。このメモ一つで、基本的な使い方と使えるマークダウン記法をすべて確認できます。

![TB's Notepad](images/welcome.png "align=center")

-# このメモもふつうのメモです。自由に書き換えたり削除したりしてかまいません。

## はじめにやること

- [x] TB's Notepad を手に入れる
- [ ] 左のサイドバーの **新しいメモ** で最初のメモを作る
- [ ] 右上の ☀ / 🌙 でライト · ダークを切り替えてみる
- [ ] 上の画像をクリックしてサイズと位置を変えてみる
- [ ] 空の行で `/` を打ってコマンド一覧を開いてみる
- [ ] Ctrl+E でこのメモのソース (マークダウン記号) を見る

## 画面の見どころ

- **左のサイドバー**: 検索、新しいメモ、フォルダーを追加、そして フォルダー › サブフォルダー › メモ の一覧
- **上部のバー**: 今のメモの場所 (フォルダー / 名前)、検索、ソース表示、ライト · ダーク、設定、⋯ メニュー
- **書式ツールバー**: 太字 · 斜体 · 取り消し線 · コード · 見出し 1~3 · リスト · ToDo · 引用 · コードブロック · 表 · 区切り線 · リンク · 画像 · 音声 · 動画 · ファイルへのリンク
- **下部のステータスバー**: 行 · 列、文字数、保存状態、エンコード、改行コード、文字サイズ

## メモの作成と整理

- **新しいメモ** (Ctrl+N): 今見ているフォルダーにすぐ作られます。1 行目に書いた文がそのままファイル名になります。
- **自動保存**: 入力を止めるとすぐに保存されます。手動で保存する必要はありません。
- **フォルダーを追加**: メモを置くフォルダーをサイドバーに加えます。フォルダーをウィンドウにドラッグしても OK です。
- フォルダー横の **+** でそのフォルダーに新しいメモを作ります。フォルダーの中にいくつでもフォルダーを作れます。
- メモやフォルダーを **右クリック** すると、新しいフォルダー、名前を変更 (F2)、エクスプローラーで表示、ごみ箱に移動が出ます。
- **検索** (Ctrl+P): すべてのフォルダーからファイル名と内容をまとめて探します。
- サイドバーでメモやフォルダーを **ほかのフォルダーにドラッグ** すると移動します。メモ内の画像 · リンクと、そのメモを指していたほかのメモのリンクも一緒に直します。
- ほかの場所のファイルはウィンドウにドラッグするか、⋯ › ファイルを開く (Ctrl+O) で開きます。サイドバーの「開いているドキュメント」に表示されます。

## `/` コマンド

ショートカットを覚えなくても大丈夫。行の先頭かスペースのあとで `/` を打つと、できることの一覧が出ます。

- 続けて文字を打つと一覧が絞り込まれます: `/見出し`、`/リンク`、`/h2`、`/todo`。
- ↑ ↓ で選んで **Enter** (または Tab、クリック) で実行します。打った `/キーワード` は消えます。
- **スペース** を打つか Esc を押すと一覧が閉じ、`/` はふつうの文字として残ります。
- 入っているコマンド: 見出し 1~3 · 箇条書き · 番号付きリスト · ToDo · 引用 · 小さい文字 · コードブロック · 表 · 区切り線 · Web リンク · メモへのリンク · この行へのリンクをコピー · ファイルへのリンク · フォルダーへのリンク · 画像 · 音声 · 動画 · クリップボードの画像 · 日付と時刻 · 今日の日付
- `10/15` や `a/b` のように文字のすぐあとの `/` では開きません。

## リストとトグル

- 箇条書き · 番号付きリスト · ToDo · 引用の行で **Enter** を押すと、次の行に同じ記号が続きます。空の項目でもう一度押すとリストが終わります。
- **Tab** / **Shift+Tab** でリスト項目をインデント · アウトデントします。
- 行の先頭で `>>` とスペースを打つと **トグル** (開いたり閉じたりできるブロック) になります。`/トグル` や書式メニューからも入れられます。
- 見出しの前の ▶ をクリックするか、見出しの行で **Ctrl+Enter** を押すと開閉します。中にはリストや画像など何でも書けます。
- トグルは GitHub や VS Code でも開閉できる `<details>` 形式で保存されます。

## マークダウン記法

記号を書くとすぐに書式が表示され、記号はカーソルのある行でだけ薄く見えます。ツールバーやショートカットでも入れられます。

### 文字の装飾

- `**太字**` → **太字** (Ctrl+B)
- `*斜体*` → *斜体* (Ctrl+I)
- `~~取り消し線~~` → ~~取り消し線~~
- `` `コード` `` → `コード`
- `[リンクの文字](https://example.com)` → [リンクの文字](https://example.com) (Ctrl+K、**Ctrl+クリック** で開く)
- アドレスをそのまま書いてもリンクになります: https://example.com
- `[議事録](会議/10月.md)` → ほかのメモへのリンク。**Ctrl+クリック** でそのメモが開きます
- `[決定事項](会議/10月.md#決定事項)` · `[12 行目](会議/10月.md#L12)` → そのメモの見出しや行へ直接移動
- `[先頭へ](#L1)` · `[マークダウン記法](#マークダウン記法)` → 今のメモの中で移動: [マークダウン記法へ](#マークダウン記法)
- `[会議フォルダー](会議)` → メモフォルダー内のフォルダーならサイドバーで開いて表示します
- `[報告書](C:/資料/報告書.pdf)` → メモ以外のファイルやほかの場所のフォルダーはエクスプローラーで開きます (スペースを含むパスは `<...>` で囲みます)

### 行の書式 (行の先頭に書きます)

- `# 見出し` · `## 見出し` · `### 見出し` → 大きい見出しから小さい見出しまで (Ctrl+Alt+1~3)
- `- 項目` → 箇条書き (前にスペースを 2 つ入れるとサブリスト)
- `1. 項目` → 番号付きリスト
- `- [ ] やること` · `- [x] 済んだこと` → チェックボックス (クリックでチェック)
- `> 引用` → 左に線のある引用
- `-# 小さい文字` → 小さいグレーの補足
- `>> 見出し` → 開閉できるトグル (スペースを打った瞬間に変わります)
- `---` → 横の区切り線

### 複数行の書式

- コードブロック: 行頭にバッククォート 3 つ (```) を書いた行で上下を囲みます。1 行目のあとに言語名を書いてもかまいません。
- 表: `| セル | セル |` のように縦線でセルを区切ります。2 行目は `| --- | --- |` で、`:---:` は中央 · `---:` は右揃えです。カーソルが外にあると表として表示され、クリックすると編集できるようにソースに戻ります。`/表` ですぐに挿入できます。

### 画像 · 音声 · 動画

- `![説明](images/画像.png)` → 画像だけの行は、その場所に画像が表示されます。
- `![説明](images/画像.png "width=50% align=center")` → サイズ (本文の幅の %) と横の位置 (left · center · right)
- `![説明](音楽/歌.mp3)` → 音声ファイルは再生バー付きの音声カードに (mp3 · wav · flac · ogg · m4a · aac)
- `![説明](動画/クリップ.mp4)` → 動画ファイルは最初の場面が見える動画カードに (mp4 · webm · mkv · mov · avi · wmv)

## 画像を入れる

- 画像を **コピーして Ctrl+V** すると、メモ横の `images` フォルダーに PNG で保存され、すぐに入ります。
- 画像ファイルをウィンドウに **ドラッグ** するか、ツールバーの画像ボタンでファイルを選んでもかまいません。
- 画像を **クリック** するとツールバーが出ます: 25 · 50 · 75 · 100% · 元のサイズ、左 · 中央 · 右、削除
- 選んだ画像の **角をドラッグ** すると Word のようにサイズが変わります。Delete で削除、Esc で選択解除。
- カーソルは画像の前か後ろにだけ止まります。画像のあとで Enter を押すと下に新しい行ができます。
- ほかの場所にある画像は、入れるときや保存するときにメモのフォルダーへコピーして一緒に保管します (設定でオフにできます)。

## 音声と動画

- ツールバーの画像ボタン (または ⋯ › 編集 › 画像 · 音声 · 動画を挿入) で音声 · 動画ファイルを選ぶか、ウィンドウに **ドラッグ** します。
- **音声** はメモの中ですぐに聞けます: ▶ で再生 · 一時停止、再生バーをクリックかドラッグして好きな位置へ。
- 音声カード右の **スピーカーと小さなバー** で音量を変えます。スピーカーをクリックでミュート、もう一度でミュート解除。音量は記憶されます。
- **動画** は最初の場面が見えるカードになり、中央の ▶ をクリックするかカードをダブルクリックすると既定の動画プレーヤーで開きます。
- カードも画像と同じようにクリックしてサイズ · 位置を変えたり削除したりできます。
- 音声 · 動画はファイルが大きいので、メモのフォルダーへコピーせず元のファイルを指します。ファイルを移動するとカードに「ファイルが見つかりません」と表示されます。

## メモどうしのリンク

- **メモへのリンクを挿入** (Ctrl+Shift+K、または ⋯ › 編集): メモ · フォルダー名で探して選ぶとリンクが入ります。
- **この行へのリンクをコピー** (Ctrl+Shift+L): カーソルのある行へのリンクをコピーします。見出しの行ならその見出しへのリンクになります。ほかのメモで Ctrl+V すると、そのメモ基準のパスで入ります。
- サイドバーでメモやフォルダーを **右クリック › ハイパーリンクをコピー** してもかまいません。
- 本文で文字を選んで **右クリック › ハイパーリンクをコピー** すると、その文字をリンクの文字にして、その行へのリンクをコピーします。本文の右クリックメニューには切り取り · コピー · 貼り付け · リンクを作成もあります。
- リンクを **Ctrl+クリック** すると、メモはアプリで開き (その行 · 見出しへ移動)、フォルダーはサイドバーで開きます。

## ファイル · フォルダーへのリンク

- ツールバーのフォルダーボタン (または ⋯ › 編集 › ファイルへのリンクを挿入 · フォルダーへのリンクを挿入) でこの PC のファイルやフォルダーを選ぶとリンクが入ります。
- pdf · Excel · 圧縮ファイルのようにメモとして開けないファイルをウィンドウにドラッグしてもリンクになります。フォルダーは **Shift** を押しながらドロップするとリンクになります。
- エクスプローラーでファイルを **コピーして Ctrl+V** してもかまいません: 画像 · 音声 · 動画はそのまま表示され、それ以外はリンクとして入ります。
- リンクを **Ctrl+クリック** すると、フォルダーはエクスプローラーで開き、ファイルはエクスプローラーでそのファイルが選ばれた状態で開きます。メモフォルダー内のメモ · フォルダーはアプリの中で開きます。

## 表示と見た目

- **ソース表示** (Ctrl+E): マークダウン記号を表示したまま編集します。もう一度押すと戻ります。
- **テーマ**: 右上の ☀ / 🌙 でライト · ダーク、設定 › テーマと色 で 8 つのテーマとカスタムカラー
- **フォント**: 設定 › フォント で本文 · ソース表示 · 画面のフォントと拡大率
- **文字サイズ**: Ctrl+マウスホイール、Ctrl+= / Ctrl+-、Ctrl+0 で標準サイズ
- **サイドバー** の表示切り替え: Ctrl+\
- そのほか 設定 › エディター: 言語、行番号、本文の幅の制限、書式ツールバー、ステータスバー、常に手前に表示
- 全画面: F11

## 検索とファイル

- 検索 Ctrl+F、置換 Ctrl+H、次 · 前を検索 F3 · Shift+F3
- 日付と時刻を挿入: F5
- .txt ファイルは書式なしでそのまま開き、元のファイル · エンコード (UTF-8、ANSI など) · 改行コードのまま保存します。
- エンコードと改行コード (CRLF · LF) は下のステータスバーをクリックして変えます。
- ⋯ › HTML として書き出す で Web ページとして保存できます。音声 · 動画はブラウザーのプレーヤーになります。
- **以前のバージョン** (⋯ › 編集 › 以前のバージョン、またはサイドバーで右クリック): 編集中 5 分ごと、また大きく削除したときに残した内容を見て戻せます。
- アプリの外でメモが変わると自動で再読み込みします。両方で変更した場合はどちらを残すか尋ねます。

## AI といっしょに使う

Claude などの AI アプリが、この PC のメモを読み書きできます (クラウド · ログインなし)。AI アプリの設定に `TB-Notepad.exe --mcp` を登録すると、メモの一覧表示、読み取り、検索、作成、編集ができます。

-# 設定と開いていたドキュメントの記録は %APPDATA%\tb-notepad に保存されます。実行ファイルの横に portable.txt を置くと、実行ファイル横の data フォルダーに保存します。
