# TB's Notepad에 오신 것을 환영합니다

가볍고 쉬운 **마크다운 메모장**입니다. *기울임*, ~~취소선~~, `인라인 코드`를 지원합니다.

![배너](images/banner.png)

## 할 일

- [x] 메모장 설치하기
- [ ] 테마 바꿔 보기 (오른쪽 위 ⚙ › 테마와 색)
- [ ] 이미지를 창에 끌어다 놓기

## 목록과 인용

1. Ctrl+E 로 마크다운 원본 보기
2. Ctrl+휠 로 글자 크기 조절
3. 이미지를 복사한 뒤 Ctrl+V 로 바로 붙여넣기

> 좋은 도구는 눈에 띄지 않는다.

| 기능 | 단축키 |
| --- | --- |
| 찾기 | Ctrl+F |
| 바꾸기 | Ctrl+H |
